# Folder Analysis Tool

> See where your disk space goes: a recursive folder scan with a size tree and a file-size distribution chart.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![Tkinter](https://img.shields.io/badge/Tkinter-3776AB) ![pandas](https://img.shields.io/badge/pandas-150458?logo=pandas&logoColor=white) ![seaborn](https://img.shields.io/badge/seaborn-4C72B0)

## Highlights

- Recursive scan of any folder.
- Tree view with each item's size and share of its parent folder.
- File-size distribution chart from 1 KB to 100 MB+.

## Design

`DirectoryScanner` handles the recursive scan and size data; `TreeApp` renders the Tkinter interface with an embedded chart.
